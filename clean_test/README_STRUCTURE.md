# clean_test Directory Purpose

`clean_test/` is a clean validation fixture mirror used to cross-check reproducibility and rerun the same pipeline in an isolated tree.

- **Canonical project location:** repository root (`/`)
- **Validation mirror:** `clean_test/`

When running the main project, follow the root-level commands and files (`requirements.txt`, `run_all.py`, `app.py`, `src/`, `tests/`).
